# Flask API Project

## Description
This is a Flask REST API with authentication and JWT-based authorization.

## Features
- User Authentication
- JWT Token Security
- RESTful API endpoints
- Error handling and validations

## Setup Instructions

```bash
git clone https://github.com/vijayaparani/flask-api.git
cd flask-api
python -m venv venv
source venv/bin/activate  # (Windows: venv\Scripts\activate)
pip install -r requirements.txt
python run.py
